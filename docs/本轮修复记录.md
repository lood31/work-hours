# 本轮修复记录

## 范围

按用户确认的计划，修复草稿隐私、总负责人无个人填报、退回原因保存、空工时显示和Excel样式/长备注。不会批删测试数据或修改旧导出快照。

## 变更说明

- 草稿内容和未提交历史仅所属学生可读取；组负责人/总负责人只见授权组的草稿数量。历史、预检、作废及保存接口同步约束；新导出只记录草稿数量，不再保存草稿正文。
- 总负责人默认月度总览，不显示/允许个人填报；不能被代录为工时归属人。普通学生、组长仍可个人填报。总代录他人管理工时必须正式提交，并由另一人审核。
- 退回记录保存修改但未重提时，当前退回原因保留；正式重提后清理当前原因，历史仍在。
- 空工时显示“未填写”，真实0小时仍显示0，不改变正式金额计算。
- 新导出使用格式2：表头30pt、明细/合计最少25pt、垂直居中；个人合计浅色#F3F2EE、组内合计#E6E5DF；本组合计工时D列，金额E列左对齐。
- 行高按换行与显示宽度估算，超过单行高度上限的文字续行，工时只在首行计入。格式1旧生成器独立保留，旧版本下载保持旧版式。
