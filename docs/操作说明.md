# 简短操作说明

## 学生

1. 打开负责人邀请链接，填写姓名、文本学号及至少10位密码。已有账号先登录再打开新组邀请链接，避免重复账号。
2. 登录“我的工时”，选择统计月份。跨组学生在组别筛选中切换填报范围；不需要每条重新输入组别、月份。
3. 新增记录：姓名学号自动带入，只填写工作内容、工时、备注。可新增多条。
4. “保存草稿”允许未填完；“提交审核”检查必填项。所有操作需主动保存，没有自动保存。
5. 车费50.01元可通过折算工具得到2.0004小时；在内容或备注写明原金额、用途及折算说明，不另加金额。
6. 退回原因直接显示；修改后重新提交。通过后可看到最终确认工时和调整原因。
7. 已通过记录修改时会明确提醒重新审核；保存后转“修改后待审核”、取消本组核对，当前版暂不进入正式导出。
8. 修改/审核历史可在记录详情展开。未通过记录可说明原因后作废；已通过记录请负责人作废，旧版不会删除。

## 组负责人

1. 进入“审核工作台”，按月份、组别、姓名/学号、状态筛选。
2. 查看五项、原通过版与历史。确认通过，或填写原因退回；调整工时也必须写原因。
3. 只能处理当前授权组，不能自审，也不能审核本人代录的记录。
4. 管理工时可用“代录管理工时”绑定本组成员并说明依据；请另一负责人或总负责人审核。不会自动生成组长薪酬。
5. 待审全部处理后点击“核对并提交本组”。草稿/退回如需留待下次，明确确认本次排除。
6. 后续补报、修改、作废或审核结果变化会取消核对。重新处理后再次核对即可。
7. “成员与邀请”可生成本组普通成员邀请，7天一次性使用；错误转发时可吊销。不能通过邀请自行授予审核权限。

## 总负责人

1. “月度总览”查看五组核对状态、变化原因、人数、工时、金额。组状态与记录状态分开展示。
2. “成员与邀请”邀请普通成员，再在成员行授予/撤销组审核权限。交接不会重写原审核历史。
3. “导出与版本”重新预检，确认月份、已通过数据、未核对组、排除明细和影响。未核定的申报金额只是估算。
4. 默认等待完整核对；若需要部分导出，必须勾选明确确认。预检后数据变化会阻止旧确认继续生成，要求重新预览。
5. 生成新版本后下载五组xlsx；版本档案可查看新增、修改、移出及重新进入范围，并重新下载旧版。
6. 已通过、已导出只是整理进度，系统不记录款项已到账或完成支付。

## 保存失败/冲突

- 表单失败时保留当前输入，可重试；重复请求不会生成相同记录或相同导出版本。
- 提示“记录已变化”时，不会自动覆盖别人修改。保留当前输入，重新打开详情对比后再处理。
- 需要放弃表单时明确确认。刷新整个浏览器前尚未保存的输入不保证恢复；已保存内容存数据库。
